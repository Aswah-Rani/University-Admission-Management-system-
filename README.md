 University Admission Management System (SQL Database Project)
📌 Overview
This project is a relational database system designed to automate and manage the university admission process. It handles student registration, merit calculation, fee management, and hostel allocation through a structured and normalized database design.

 🎯 Features
* Student registration and admission processing
* Merit calculation based on defined criteria
* Fee management system
* Hostel allocation module
* Secure and structured data storage
🛠️ Technologies Used
* SQL (MySQL / Oracle / SQL Server – mention what you used)
* Database Design Principles
* Normalization (up to BCNF)
### 🗂️ Database Design
* Designed 22 relational tables
* Proper use of Primary Keys and Foreign Keys
* Fully normalized database structure (up to BCNF)
* Ensured data integrity and reduced redundancy

2. Admission Management
3. Merit Calculation
4. Fee Management
